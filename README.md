# Games-plugin

Немного развлечений в редакторы Р7-Офис и OnlyOffice :)

<img src="https://github.com/VNexsus/Games-plugin/blob/main/2048.png" height="200"><img src="https://github.com/VNexsus/Games-plugin/blob/main/LastSpartan.png" height="200"><img src="https://github.com/VNexsus/Games-plugin/blob/main/Zuma.png" height="200">

Плагин добавляет новую вкладку "Игры":
- 2048
- Last Spartan
- Zuma

## Как установить
* Для установки плагина скачайте файл games.plugin следуйте инструкциям на сайте <a href="https://support.r7-office.ru/desktop_editors/api_desktop_editors/api_desktop_editors_general/adding-plugins/">Р7-Офиc</a>

## Использованные компоненты
* JQuery <a href="https://github.com/jquery/jquery">(GitHub)</a>
* 2048 <a href="http://gabrielecirulli.github.io/2048/">(GitHub)</a>
* Last Spartan <a href="https://github.com/ferronsays/js13k-TheLastSpartan/">(GitHub)</a>
* Zuma <a href="https://github.com/lin-ting-yu/Zuma">(GitHub)</a>
